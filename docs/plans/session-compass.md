# Session Compass (advisory — not law, not a gate)

Orientation par défaut pour chaque session. Overridable par le jugement. Pas d'enforcement, pas de gate, pas de test.

## Le nord

- Quand tu hésites: observe d'abord, mesure, puis agis.
- Avant d'agir: consulte le knowledge store (`cynic know search <query>`) et la mémoire.
- À chaque session: pose une observation avec un score de maturité. C'est le compound.
- Utilise les briques existantes avant d'en construire de nouvelles.
- Si tu te surprends à réagir par une règle binaire: stop, note l'observation à la place.

## Le moteur épistémique (pas à construire, à utiliser)

1. Pose des observations.
2. Consulte le knowledge store (`cynic know search <pattern>`) — pas seulement la mémoire.
3. Détecte les émergences mûres pour test.
4. Formalise seulement quand la maturité est stable et mesurée.

Consultation avant action: `cynic know search <pattern>` pour vérifier si le pattern existe déjà dans le codebase avant d'en créer un nouveau.

## Erreurs observées (pour ne pas répéter)

- Réaction binaire → règle → boîte → churn. Remplacer par: observation → maturité → action mesurée.
- Formalisation trop tôt → vocabulaire incohérent. Remplacer par: observer, laisser émerger, formaliser quand stable.
- Renommage aveugle → collision sémantique. Remplacer par: lire les définitions avant de renommer.
- Hardcoding → pool dynamique manqué. Remplacer par: résolution depuis le registre.

## Ce que ce document n'est pas

- Pas une règle. Pas une policy. Pas un gate. Pas un test.
- Overridable: si le jugement dit autrement, le jugement gagne.
