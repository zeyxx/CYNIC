# KYON - Épistémologie et Hypergraphe de Connaissances

## 1. La Falsification Popperienne dans l'Organisme
KYON ne repose sur aucun dogme pré-codé. Il applique une méthode scientifique continue à l'humain qu'il protège.
Le Persona génère des théories, les teste via la boucle cybernétique (le *LOCKDOWN* ou l'observation), et utilise la réaction de l'humain (la "meta-observation") pour valider ou falsifier la théorie initiale.

*Exemple de Falsification :*
- **Théorie initiale (Issue de la littérature)** : La lecture de flux courts augmente la pression métabolique (Dopamine baseline drop).
- **Test Cybernétique** : L'humain scrolle sur X (Twitter) pendant 20 minutes. Le rythme cardiaque ou la fréquence de scroll diminue. 
- **Meta-Observation de l'humain** : "Je lisais un thread complexe sur l'astrophysique, je n'étais pas en boucle."
- **Mise à jour de l'Hypergraphe** : Le nœud `[Réseau Social X]` -> `[Toxicité]` est falsifié contextuellement. Une nouvelle arête est créée : `[Réseau Social X] + [Scroll Lent] + [Sémantique: Science]` -> `[État de Flow cognitif]`.

## 2. L'Hypergraphe (Le Cerveau Profond)
Plutôt qu'un LLM qui hallucine, KYON s'appuiera sur un Hypergraphe local (potentiellement propulsé par SurrealDB Edge).

### Nœuds de l'Hypergraphe :
1. **Les Axiomes Scientifiques (RAG)** : Papiers de neurobiologie (Circuits de récompense, Huberman, Sapolsky), psychologie cognitive (Kahneman).
2. **Les Axiomes Philosophiques** : Textes Stoïciens (Marc-Aurèle, Épictète), Cyniques (Diogène).
3. **Les États Physiologiques** : Pression métabolique, Vitesse de Scroll, Tension.
4. **Les Entités Numériques** : Apps, types d'UX (Infinite Scroll, Pull-to-refresh).

### Arêtes (Relations complexes) :
Dans un hypergraphe, une arête peut relier plus de deux nœuds.
*Exemple d'arête hypergraphique :*
`(Axiome: Épuisement de l'Ego) + (État: 22h00) + (Entité: Algorithme de Recommandation) === [PRODUIT] ===> (Comportement: Doomscrolling)`.

## 3. L'Architecture Edge
1. **Couche 1 (Sensors)** : Collecte les données brutes.
2. **Couche 2 (Metabolism)** : Compresse et détecte les anomalies.
3. **Couche 3 (Hypergraph RAG + LLM)** : 
   - Le LLM interroge l'Hypergraphe embarqué pour trouver les théories neurobiologiques correspondant au contexte actuel.
   - Il agit.
   - Il enregistre le résultat de l'action pour ajuster le poids des arêtes de l'hypergraphe (Apprentissage par le réel).
