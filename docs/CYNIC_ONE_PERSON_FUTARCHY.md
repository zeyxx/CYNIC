# CYNIC : One-Person Enterprise & Futarchy Manifest

Status: normative foundation.

Ce contrat consolide les concepts extraits des interfaces graphiques exploratoires et des brouillons initiaux (Talaria, ASDFASDFA, Futardio). Il formalise la doctrine de transparence radicale et de gouvernance par les marchés (Futarchy) pour une "One-Person Enterprise" (OPE) augmentée par l'organisme CYNIC.

## 1. La Transparence Quasi-Exhaustive (Proof-of-History)
Une One-Person Enterprise (OPE) ne peut scaler la confiance qu'à travers une transparence radicale de ses actions.
- **Le flux public (`public-ui`)** agit comme un registre (ledger) immuable du travail accompli.
- **Build Proofs :** Chaque décision, chaque ligne de code, chaque sprint est compressé en "Preuve de build" exposée publiquement. Le "build-proof compressor" convertit les observations du Kernel en cartes publiques.
- La transparence n'est pas un reporting, c'est l'interface de l'entreprise elle-même.

## 2. Le Modèle de Futarchy (Markets Decide)
La Futarchy est le rail de coordination. "Le marché décide du prix, le prix est un signal, pas la vérité".
L'écosystème se divise selon un manifeste clair :
- **Cult Distribution Shell ($ASDFASDFA)** : Couche de mème, distribution. Pas d'equity, pas de promesse cachée.
- **Véhicule Légal (Talaria)** : Contient les contrats et la PI.
- **Judgment Engine (CYNIC)** : Score le doute, refuse la certitude absolue (principe de Kenosis). Le moteur de jugement ne donne jamais de conseil d'investissement.
- **Coordination (Futarchy)** : Résolution des décisions via des paris sur le marché. (Ex: "Faut-il lancer le cult-screener avant le token CYNIC ?").

## 3. Topologie de l'Opérateur (Edge vs Kernel)
Le concept topologique découvert par observation des UI :
- **Public Edge** : Interface de transparence et portail externe (ex: Vercel).
- **Local Fallback** : Miroir sécurisé, utilisable hors-ligne via Tailscale.
- **Private Kernel** : Le cœur de l'organisme, protégé par l'authentification Wallet (Wallet Session).

## 4. L'Émergence du Contrat
Ce document est la fusion de dizaines de brouillons fragmentés et d'interfaces exploratoires (quarantined-ui). Son existence rend ces anciens artefacts obsolètes. L'organisme évolue par cristallisation.
