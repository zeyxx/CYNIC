# CYNIC : Doctrine Corporative & Stratégie IP (TALARIA)

Ce document fige la structure juridique, le calendrier de déploiement et la stratégie de Propriété Intellectuelle (IP) de l'entité mère française, garantissant le contrôle absolu du fondateur et la protection contre le pillage du code.

---

## 1. La Forme Juridique : TALARIA SASU

Pour garantir un "Pare-Feu Sanitaire" absolu et une prise de décision unilatérale, l'entité légale française est immatriculée sous la forme d'une **SASU (Société par Actions Simplifiée Unipersonnelle)**.

*   **Capital & Contrôle :** 100 % des parts sont détenues par le fondateur (Jean). Il en est le Président exclusif.
*   **Zéro Equity Externe :** Conformément au Pacte des Fondateurs, ni les alliés de la genèse (Stanislas), ni la famille, ni les futurs investisseurs (STAMP) ne reçoivent de parts de la SASU. Leur alignement financier se fait exclusivement via le token offshore.
*   **Agilité :** La SASU permet d'éviter la lourdeur des Assemblées Générales ordinaires (AGO) avec de multiples actionnaires.

## 3. Stratégie de Propriété Intellectuelle (Armure IP)

Le Web3 exige de l'Open Source pour générer de la confiance, mais cette exigence est souvent fatale pour les entreprises naïves qui se font "forker" (copier) par des cartels de VCs. TALARIA applique le modèle **Open Core Blindé**.

### A. La Licence BSL (Business Source License)
Le code on-chain (`cynic-kernel`) n'est **pas** publié sous une licence libre permissive (MIT/Apache) dès le premier jour.
*   Il est publié sous **BSL**.
*   **L'effet :** Le code est 100% lisible et auditable par le public (pour la confiance), mais il est **légalement interdit de l'utiliser à des fins commerciales en production pendant 3 ans**.
*   Si un concurrent déploie un clone commercial d'Odysseum, TALARIA le détruit juridiquement. Après 3 ans, la licence bascule automatiquement en Open Source (GPL).

### B. Le Code Propriétaire (Closed Source)
Seul le contrat blockchain est visible. Tout ce qui fait "l'intelligence" de l'écosystème reste la propriété privée et fermée de TALARIA SASU :
*   L'interface utilisateur (UI) ultra-premium d'Odysseum.
*   Le **Cognitive CAPTCHA** (algorithmes de Machine Learning pour le Proof of Humanity).
*   Le **Quantum Treasury Bot** (l'algorithme d'achat aléatoire anti-MEV de `$ASDF`).
*   Le proxy local d'analyse comportementale (`cynic-observer`).

### C. La Forteresse des Marques (INPI)
Dès le T1 (Août 2026), TALARIA SASU dépose les marques à l'INPI (France) et EUIPO (Europe) :
*   **CYNIC**
*   **Odysseum**
*   **E-Score**

Même si un pirate parvient à cloner le code dans 3 ans, il lui sera interdit d'utiliser les termes officiels, garantissant que l'attention culturelle et la liquidité (`$ASDF`) restent rattachées au réseau originel.
