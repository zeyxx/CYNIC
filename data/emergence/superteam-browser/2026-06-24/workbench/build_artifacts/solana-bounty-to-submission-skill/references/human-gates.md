# Human Gates

Stop and request explicit approval before:

- submitting a bounty, grant, form, PR, issue, report, or public comment
- posting to X, Discord, Telegram, Farcaster, LinkedIn, YouTube, TikTok, or a blog
- authenticating with a personal account
- connecting a wallet
- signing any message or transaction
- sending, trading, staking, depositing, borrowing, lending, or bridging funds
- using sponsor API keys or test balances
- disclosing a suspected vulnerability
- creating a public repo that reveals private strategy or infrastructure

The approval request must include:

- exact destination
- exact payload or diff
- irreversible effects
- private information exposure
- financial or reputational risk
- rollback option, if any

Without approval, prepare drafts and local artifacts only.
