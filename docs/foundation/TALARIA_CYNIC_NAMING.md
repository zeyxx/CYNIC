# TALARIA / CYNIC Naming

Ce document fixe la separation entre le nom legal public et le nom technique interne.

---

## 1. Decision

```text
TALARIA SAS = legal genesis entity.
CYNIC = framework, protocol stack, Kernel, judge and internal engine.
```

TALARIA est le nom symbolique et public issu de l'emergence Futard.io / ICO attempt.

CYNIC est le nom du framework souverain de jugement, du Kernel, de l'E-Score, de l'infrastructure cognitive et de la stack protocolaire.

---

## 2. Separation Des Roles

| Nom | Role | Fonction |
|-----|------|----------|
| TALARIA SAS | Entite legale genesis | Statuts, contrats, IP, wallets legaux, fiscalite, gouvernance corporate |
| TALARIA | Marque publique possible | Interfaces, produits publics, communication institutionnelle |
| CYNIC Framework | Moteur technique | Kernel, judge, E-Score, agents, proofs, data, governance signals |
| CYNIC Protocol | Couche protocolaire | Smart contracts, treasuries, rewards, operator registry, E-Score weights |
| `$CYNIC` | Token/protocol asset | Access, compute, staking, rewards de contribution, gouvernance protocolaire, culture memetique |
| CYNIC WORLD ORDER | Meme shell | Culture anti-bullshit, contre-narratif au Great Reset, ralliement communautaire |

---

TALARIA SAS est l'entite legale genesis qui opere, protege et gouverne le framework/protocole CYNIC.

## 5. Token Naming

Decision :

```text
Token symbol = $CYNIC.
```

Le nom `$CYNIC` est retenu parce qu'il represente l'acces, la gouvernance protocolaire, le staking, le compute, le E-Score et la culture memetique du framework CYNIC, pas les actions de TALARIA SAS.

Cette separation renforce le token/equity firewall :

```text
TALARIA SAS = legal company.
CYNIC Protocol = network/protocol.
$CYNIC = protocol/framework/meme asset.
```

Un token `$TALARIA` serait plus doux et grand public, mais il creerait une ambiguite plus forte avec l'exposition a TALARIA SAS.

`$CYNIC` maintient une distance plus nette :

```text
Holding $CYNIC does not mean owning TALARIA SAS.
```

### CYNIC WORLD ORDER

`CYNIC WORLD ORDER` est la couche culturelle et memetique du protocole. Elle peut devenir le contre-narratif public face au "Great Reset" : verite nue, anti-bullshit, preuve historique, jugement ouvert, souverainete cognitive.

Role :

- memetic shell ;
- culture communautaire ;
- signal anti-capture ;
- ralliement Solana/Web3 ;
- expression publique du CYNIC Protocol.

Limite :

```text
CYNIC WORLD ORDER is culture, not legal governance.
```

---

## 6. Red Flags

Eviter :

- "CYNIC SAS" comme entite genesis ;
- "TALARIA token gives equity" ;
- "$TALARIA" comme token principal sans reouvrir le firewall legal ;
- "TALARIA SAS is the protocol" ;
- "CYNIC owns legal rights" ;
- "The token owns TALARIA" ;
- confondre marque publique, protocole, framework et societe.

---

## 7. Definition Of Done

La separation est correcte quand :

- les droits legaux pointent vers TALARIA SAS ;
- le framework/protocol pointe vers CYNIC ;
- `$CYNIC` ne donne aucun droit aux actions de TALARIA SAS ;
- `$CYNIC` est le token protocolaire/memetique par defaut ;
- les wallets corporate appartiennent a TALARIA SAS ;
- les smart contracts appartiennent a leur gouvernance protocolaire ;
- les communications publiques ne confondent pas societe, protocole et token.
