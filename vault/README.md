1. **Human Sovereign Space**: This space holds exploratory thinking, emergent hypotheses, mathematical intuitions, thermodynamic models, and research notes.
2. **Zero Runtime Execution Authority**: Notes in this vault are **pre-legislative**. No agent or machine may use raw notes in `vault/` as execution authority or justification to mutate code or bypass runtime invariants.
3. **The Specification Gateway**: For an idea in `vault/` to become active framework code, it must be distilled into a normative specification under `specs/` (e.g. `specs/RFC-XXX.md`) with explicit invariants, bounds, and testable properties.
