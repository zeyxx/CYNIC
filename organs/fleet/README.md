# CYNIC organ-fleet

`organ-fleet` is the fleet truth aggregator. It prevents cortex sessions and the
operator from rebuilding infrastructure reality by hand.

It compares:

- `desired` and `declared` state from `infra/registry.json`
- runtime observations from providers such as Proxmox, Headscale, Synapse,
  systemd, and kernel health
- energy profiles declared on nodes

The output is JSON only. Markdown is documentation, not the runtime ledger.

## Local Check

```bash
python3 organs/fleet/src/entrypoints/cli.py report --json --registry infra/registry.json
```

Provider evidence can be passed as normalized JSON:

```bash
python3 organs/fleet/src/entrypoints/cli.py report --json \
  --registry infra/registry.json \
  --proxmox-json /tmp/proxmox.json
```

The report shape is the handoff contract for `cynic_health` and
`cynic_attention`:

```json
{
  "desired": [],
  "declared": [],
  "observed": [],
  "effective": [],
  "anomalies": [],
  "energy": {},
  "summary": {
    "status": "ok | degraded",
    "critical_targets": []
  }
}
```

`summary` is the intended minimal handoff to `cynic_health` and
`cynic_attention`; the full arrays remain available for diagnosis.

## LXC Exec Bridge

`fleet.node.exec` must not grant agents raw `pct exec`, SSH, or host sudo. LXC
execution requires a root-owned helper governed by:

- `axioms/lxc-exec-bridge-v1.json`
- `organs/fleet/policies/lxc-exec-bridge.policy.json`

Validate the policy:

```bash
python3 organs/fleet/src/entrypoints/cli.py lxc-exec-bridge validate-policy --json
```

Render the sudoers projection:

```bash
python3 organs/fleet/src/entrypoints/cli.py lxc-exec-bridge render-sudoers
```

Render the non-mutating installation plan:

```bash
python3 organs/fleet/src/entrypoints/cli.py lxc-exec-bridge install-plan
```

Build a non-mutating activation bundle:

```bash
make lxc-exec-bridge-bundle out=/tmp/cynic-lxc-bridge
```

This writes only to the requested output directory. A root/operator activation
step must copy those files to the Proxmox host paths declared in the manifest
and run the listed activation checks.

Check activation status from the current filesystem:

```bash
python3 organs/fleet/src/entrypoints/cli.py lxc-exec-bridge activation-status
```

This returns non-zero until the helper, policy and sudoers projection match the
contract.

The sudoers rule must authorize only the helper path, not `/usr/sbin/pct`,
`bash`, `sh`, or any provider CLI directly. Until the helper is installed and
observed on the Proxmox host, MCP `fleet_node_exec` must continue returning the
structured `precondition_missing: lxc_exec_bridge` result for LXC targets.

Helper source:

```text
organs/fleet/src/entrypoints/lxc_exec_bridge_helper.py
```

Dry-run the helper contract locally:

```bash
echo '{"node":"pve","vmid":103,"purpose":"read_only","argv":["hostname"],"agent_id":"cortex-test"}' \
  | python3 organs/fleet/src/entrypoints/lxc_exec_bridge_helper.py --dry-run
```
