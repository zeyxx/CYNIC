# Cap Nord — flotte CYNIC

1 humain opérationnel dans tout domaine ; souverainetés numérique et cognitive.

- Numérique : l'infra obéit sans qu'on y mette les mains (surfaces typées, baux TTL, preuves de lecture).
- Cognitive : la machine prouve ou se tait (ancrage temporel, refus fail-closed, `blocked` plutôt qu'improvisé).
- Méthode : la flotte pousse par les plaies, pas par le plan — chaque mécanisme naît d'un frottement réel, mesuré, consigné.
