# CYNIC Attention Sovereignty Strategy

## 1. Purpose

This document crystallizes the strategic direction of CYNIC and Kyon:
sovereignty of attention and cognition in the agentic era, where code is
abundant and authentic human attention is the scarce input that keeps models
alive.

## 2. Thesis

> In an era of abundant code, models and synthetic content, the last scarce
> resource is authenticated human attention. Whoever owns the personal layer
> where that attention lives owns the economic and cognitive frontier.

CYNIC provides the sovereign infrastructure for processing, storage and proof.
Kyon is the personal edge that captures, protects and proves the user's
cognitive boundary.

## 3. The Moat: ENCRYPT THE MONEY

Data is money in the agentic era, but only when it is encrypted, owned and
consented.

| Move | Effect |
|---|---|
| personal data encrypted by default | not scrapable without explicit consent |
| attention measured locally, never sent raw | platforms cannot monetize it silently |
| local proof of consent | user becomes the authority of their own contribution |
| opt-in only for any downstream use | models train only on offered material |
| complete exit possible | value is tied to the person, not to a service |

The moat is not the codebase. It is the trust relationship between a person
and their own cognition.

## 4. Architecture

- **Kyon Mobile**: local-first personal membrane on Android.
- **Kyon Desktop**: same membrane on Linux and Windows first, macOS later.
- **CYNIC**: sovereign infrastructure for compute, storage, coordination, proof.
- **Federation**: later, nodes cooperate by minimal attestations.

The kernel is an adapter, not a dependency. Kyon must protect even when CYNIC
is absent.

## 5. Non-negotiable Principles

1. Personal data never leaves the device without explicit consent.
2. No raw attention or cognition is uploaded by default.
3. Consent is a versioned, inspectable boundary.
4. Every action is explainable.
5. The user can export, delete or refuse at any time.
6. CYNIC never becomes the owner of personal data.
7. Local proof is primary; prose is not authority.

## 6. Roadmap

1. **Kyon Mobile v0**: local-first shield, boundary coach, encrypted vault, explicit export.
2. **Kyon Desktop v0**: same core membrane on Linux/Windows.
3. **CYNIC integration**: opt-in sync, never critical path.
4. **Federation v0**: attestation-based cooperation.
5. **Prove the moat**: no silent extraction, no third-party dashboard, no hidden policy.

## 7. Proof Criteria

A release is coherent only when:

- it works offline;
- no network call occurs by default;
- consent is versioned and exportable;
- the user can delete everything;
- raw data is never captured automatically;
- a third party receives nothing without explicit action;
- local read-back proves what the system did.

## 8. Open Questions

- Which encryption suite is canonical for the vault?
- What is the minimum consent ledger required for export?
- How is desktop parity achieved without duplicating Android code?
- What exact attestation is enough for federation?
- How is user authority proved locally at runtime?

## 9. Conclusion

The strategy is not to collect more data. It is to return ownership of
attention, memory and cognition to the person, and to make that ownership
provable.
